# مؤسسة عدن للديكور | Adan Decor Official Platform

![Adan Decor Banner](/src/assets/images/luxury_interior_hero_1784488795242.jpg)

الموقع الرسمي والمنصة الإلكترونية المتكاملة لمؤسسة **عدن للديكور (Adan Decor)** الرائدة في تقديم حلول التصميم الداخلي الفاخر، الديكورات المودرن والكلاسيكية، التشطيبات الراقية، وأعمال الألمنيوم والنجارة في عدن واليمن.

---

## 🌟 مميزات المنصة:
- 🎨 **تصميم عصري وفاخر:** واجهة احترافية تتناسب مع الفخامة المعمارية والأعمال الهندسية الدقيقة.
- 📱 **متجاوب بالكامل:** يعمل بسلاسة فائقة على جميع الهواتف الذكية، الأجهزة اللوحية، والشاشات المكتبية.
- 🔐 **لوحة تحكم إدارية مدمجة:** لإدارة معرض الأعمال، المشاريع الفنية، استعراض الاستشارات والخدمات بكل سهولة.
- ☁️ **قاعدة بيانات سحابية:** متصل بالكامل بقاعدة بيانات **Supabase Cloud Database** لضمان سرعة البيانات وأمانها المستمر.

---

## 🛠️ التقنيات المستخدمة (Tech Stack):
- **الواجهة الأمامية (Frontend):** React, Vite, TailwindCSS & Vanilla CSS Design System.
- **الخادم البرمجي (Backend API):** Node.js, Express.js.
- **قاعدة البيانات (Database):** Supabase PostgreSQL Cloud Sync.

---

## 💻 تعليمات التشغيل المحلي والتطوير:
لتشغيل الخادم البرمجي محلياً على جهازك:

```bash
# 1. تثبيت الحزم المطلوبة
npm install

# 2. تشغيل الموقع في وضع التطوير
npm run dev

# 3. تشغيل وضع الإنتاج (Production Server)
npm run build
npm start
```
